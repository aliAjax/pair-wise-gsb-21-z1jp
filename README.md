# hxwl-07 孔探复核台

在航空维修检查清单基础上扩展的发动机孔探复核台：按发动机和站位登记叶片孔探读数，超差叶片必须经另一名放行人员复核后才能写进放行单。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5107

## 分层结构

- `src/data/reference.ts` —— 资料：发动机、站位、人员资质、仪器校准期、示例记录
- `src/domain/judgment.ts` —— 判定：增长超 1mm、仪器过期、资质失效的保留规则与放行校验
- `src/storage/local.ts` —— 本机保存：localStorage 持久化，重开页面记录仍在
- `src/pages/` —— 页面：登记读数（RegisterPage）、发动机复核（EnginePage）

## 功能

- 按发动机 + 站位登记：叶片编号、缺陷长度、深度、参照尺寸、检查人、仪器校准期
- 自动判定：损伤较上次增长 >1mm、仪器校准过期、检查人资质失效 → 只能停在「待评估」
- 待评估记录须由另一名具备有效资质的放行人员填写工程依据后放行
- 放行后读数锁定；更正另存为新版本并填写原因，旧值随版本保留
- 发动机复核页：同站位同叶片前后读数对比、增长量高亮、待办清单、版本留痕
